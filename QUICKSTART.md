# Portfolio - Rayane Laidi

## 🚀 Démarrage rapide

```bash
# Installation des dépendances
npm install

# Lancement du serveur de développement
npm run dev

# Build production
npm run build

# Démarrage du serveur de production
npm start
```

Accédez au site à l'adresse : **http://localhost:3000**

---

## 📝 Notes de développement

### Technologies utilisées

- **Next.js 16.1.6** - Framework React avec App Router
- **React 19.2.3** - Bibliothèque UI moderne
- **TypeScript 5** - Typage statique
- **Tailwind CSS 4** - Framework CSS utilitaire

### Structure des dossiers

- `src/app/` - Pages et routes (App Router Next.js)
- `src/components/` - Composants réutilisables
- `src/data/` - Données centralisées (projets, compétences)
- `public/` - Fichiers statiques (images, fonts)

### Personnalisation

- **Données** : Modifier `src/data/portfolio.ts`
- **Styles** : Modifier `src/app/globals.css` (variables CSS)
- **Composants** : Tous les fichiers `.tsx` dans `src/components/`
